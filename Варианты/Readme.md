# Материалы для подготовки к демонстрационному экзамену

## Важная информация
Представленные ниже варианты заданий **не являются официальными** (государственными) материалами.  
Они разработаны на основе анализа структуры и типовых задач оригинального экзамена и служат исключительно для тренировки и самостоятельного ознакомления с возможными форматами вопросов.

## Рекомендации по использованию
- Прорешайте все варианты, чтобы охватить максимальный спектр тем.
- Сравнивайте свои решения с эталонными (если они доступны) или обсуждайте в учебных группах.
- Обратите внимание на формулировки — в реальном экзамене они могут быть более строгими.
